# Priority Matrix

made this at 3 in the morning its rough

## Description
Priority Matrix is a lightweight web-based tool that helps you prioritize tasks using a tournament-style matrix. You can input tasks, compare them in a visual table, and automatically calculate a priority ranking based on how often each task appears.

## Features
- Enter tasks dynamically (one per line).
- Interactive editable table for comparisons.
- Automatically counts task occurrences.
- Generates a final priority list.
- Pink aesthetic interface with editable cells.

## How to Use
1. Open `index.html` in a web browser.
2. Enter your tasks in the textarea (one per line).
3. Click **Create Tournament Table**.
4. Fill the matrix cells with your comparisons.
5. Click **Calculate Priority Counts** to see the final priority ranking.
